# Инструкции для ИИ-агентов

Этот проект — учебный. Его развивает ребёнок вместе с ИИ-агентами, по одной
небольшой фиче за раз. Код должен оставаться таким, чтобы ребёнок мог его
прочитать и понять.

## Главные правила

1. **Один файл, без сборки и без зависимостей.** Вся игра — это один
   самодостаточный `index.html`: CSS в `<style>`, весь JavaScript в одном
   `<script>`. Не выноси код в отдельные файлы, не подключай ничего из
   интернета (CDN, шрифты, картинки по ссылке). Никаких npm, фреймворков,
   TypeScript, бандлеров. Игра должна работать двойным кликом по файлу.
2. **Без сервера.** Всё работает в браузере, сохранение — в `localStorage`.
3. **Маленькие шаги.** Одна фича за раз. Не переписывай то, о чём не просили.
4. **Язык:**
   - весь текст для игрока — **на русском**;
   - **команды — на английском** (`look`, `attack`, `equip sword`) — это
     намеренно, в стиле MUD-ов 90-х;
   - комментарии в коде — на русском, простыми словами;
   - имена переменных и функций — на английском.
5. **Два режима — не смешивать.**
   - **Приключение** — только клавиатура и текстовые команды. Никаких кнопок
     и кликов по карте для игровых действий (это намеренно, в стиле MUD).
     Подсказка «Что можно сделать» — это текст, а не кнопки.
   - **Строитель** — только мышка: клики по карте и редактор комнаты.
     Строительство не делается текстовыми командами.
6. **Объясняй.** После изменений коротко расскажи, что поменялось и в каком
   файле — простым языком, как школьнику.

## Как устроен код

Всё в `index.html`. Весь JS — один `<script>`, все функции глобальные.
Код разбит на части, у каждой есть заголовок-баннер в комментарии.
Части идут в таком порядке (порядок важен: сначала данные, потом то, что
их использует). Новый код клади в подходящую часть.

| Часть (заголовок) | Что там |
|---|---|
| `ВНЕШНИЙ ВИД` | CSS в `<style>`. Цвета — переменные в `:root`. |
| `СОДЕРЖИМОЕ ИГРЫ` | Контент: `ITEMS`, `MONSTERS`, `NPCS`, названия комнат. Новый монстр/предмет/друг — это просто новая запись здесь. |
| `СОСТОЯНИЕ ИГРЫ, СОХРАНЕНИЕ…` | Объект `game` (всё состояние), `newGame()`, стартовое подземелье (`buildStartingDungeon`, `addRoom`), `saveGame()`/`loadGame()`, помощники `rand`, `pick`, `chance`. |
| `МИР` | Сетка комнат (`game.rooms["x,y"]`), направления, создание/удаление комнат. y растёт на юг. |
| `ГЕРОЙ` | Здоровье, опыт и уровни, сумка, снаряжение, зелья. |
| `БОЙ` | Пошаговый бой. Бой = в комнате героя есть монстр. |
| `КОМАНДЫ ПРИКЛЮЧЕНИЯ` | Список `COMMANDS` и `runCommand()`. Новая команда — новая запись в списке. |
| `ЭКРАН` | Переключение режимов (`mode`, `setMode`), карта, текстовое окно, окно героя, подсказки «Что можно сделать». |
| `РЕЖИМ «СТРОИТЕЛЬ»` | Клики по карте и редактор выбранной комнаты (`selectedKey`). |
| `ЗАПУСК ИГРЫ` | Запуск. |

### Важные договорённости

- **Подсказки.** У каждой команды есть `suggest()` — она возвращает готовые
  варианты команды для текущей ситуации. Текст «Что можно сделать» строится
  из них автоматически. Добавляя команду, не забудь `suggest()`.
- **Слова для команд.** У каждого предмета есть `keyword` по-английски
  (`"iron sword"`); команды понимают и всё слово целиком, и его часть
  (`equip sword`). Новому предмету обязательно нужен `keyword`.
- **Магии и характеристик (СИЛ/ИНТ) пока нет** — их убрали, чтобы начать
  с простого. Они есть в `IDEAS.md` как будущие фичи.
- **Монстры и друзья в комнатах** хранятся как `{ id, hp }` и
  `{ id, talks, giftGiven }`, а их свойства берутся из `data.js` по `id`.
- **Максимум здоровья и маны** не хранится, а считается функциями
  `maxHp()` из уровня.
- **Сохранения.** Если меняешь структуру `game` (новое поле у игрока,
  комнаты и т.п.), **увеличь `SAVE_VERSION`** (часть «СОСТОЯНИЕ ИГРЫ»), иначе старое
  сохранение может сломать игру.
- Вывод в текстовое окно — `say(текст, класс)`. Классы цвета: `good`, `bad`,
  `combat`, `friend`, `build`, `loot`, `title`, `system`.

## Как проверить

Открой `index.html` в браузере, попробуй новую фичу и несколько старых
команд (`look`, `n`, `attack`) и переключись в строителя и обратно. Загляни в консоль браузера
(F12) — там не должно быть ошибок. Если что-то странное с сохранением —
набери `reset`.
