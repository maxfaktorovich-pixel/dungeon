# Инструкции для ИИ-агентов

Этот проект — учебный. Его развивает ребёнок вместе с ИИ-агентами, по одной
небольшой фиче за раз. Код должен оставаться таким, чтобы ребёнок мог его
прочитать и понять.

## Главные правила

1. **Без сборки и без зависимостей.** Чистые HTML + CSS + JavaScript.
   Никаких npm, фреймворков, TypeScript, бандлеров. Игра должна запускаться
   двойным кликом по `index.html` (поэтому — обычные `<script>`, а не ES-модули:
   модули не работают с `file://`).
2. **Без сервера.** Всё работает в браузере, сохранение — в `localStorage`.
3. **Маленькие шаги.** Одна фича за раз. Не переписывай то, о чём не просили.
4. **Язык:**
   - весь текст для игрока — **на русском**;
   - **команды — на английском** (`look`, `attack`, `cast fireball`) — это
     намеренно, в стиле MUD-ов 90-х;
   - комментарии в коде — на русском, простыми словами;
   - имена переменных и функций — на английском.
5. **Объясняй.** После изменений коротко расскажи, что поменялось и в каком
   файле — простым языком, как школьнику.

## Как устроен код

Файлы подключаются в `index.html` по порядку, все функции — глобальные.

| Файл | Что там |
|---|---|
| `js/data.js` | Контент: `ITEMS`, `SPELLS`, `MONSTERS`, `NPCS`, названия комнат. Новый монстр/предмет/друг — это просто новая запись здесь. |
| `js/game.js` | Объект `game` (всё состояние), `newGame()`, стартовые комнаты, `saveGame()`/`loadGame()`, помощники `rand`, `pick`, `chance`. |
| `js/world.js` | Сетка комнат (`game.rooms["x,y"]`), направления, создание/удаление комнат. y растёт на юг. |
| `js/player.js` | Характеристики героя, опыт и уровни, сумка, снаряжение, зелья. |
| `js/combat.js` | Пошаговый бой. Бой = в комнате игрока есть монстр. |
| `js/commands.js` | Список `COMMANDS` и `runCommand()`. Новая команда — новая запись в списке. |
| `js/ui.js` | Отрисовка карты, окна персонажа, подсказок «Что можно сделать», кисти карты. |
| `js/main.js` | Запуск. |

### Важные договорённости

- **Подсказки.** У каждой команды есть `suggest()` — она возвращает готовые
  варианты команды для текущей ситуации. Окно «Что можно сделать» строится
  из них автоматически. Добавляя команду, не забудь `suggest()`.
- **Монстры и друзья в комнатах** хранятся как `{ id, hp }` и
  `{ id, talks, giftGiven }`, а их свойства берутся из `data.js` по `id`.
- **Максимум здоровья и маны** не хранится, а считается функциями
  `maxHp()` / `maxMp()` из уровня и характеристик.
- **Сохранения.** Если меняешь структуру `game` (новое поле у игрока,
  комнаты и т.п.), **увеличь `SAVE_VERSION`** в `js/game.js`, иначе старое
  сохранение может сломать игру.
- Вывод в текстовое окно — `say(текст, класс)`. Классы цвета: `good`, `bad`,
  `combat`, `friend`, `build`, `loot`, `title`, `system`.

## Как проверить

Открой `index.html` в браузере, попробуй новую фичу и несколько старых
команд (`look`, `n`, `attack`, `build east`). Загляни в консоль браузера
(F12) — там не должно быть ошибок. Если что-то странное с сохранением —
набери `reset`.
