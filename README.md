# 🏰 Подземелье Строителя

Текстовая RPG в духе старых MUD-ов из 90-х. В ней два режима:

- **⚔️ Приключение** — бродишь по подземелью, дерёшься с монстрами, болтаешь
  с друзьями. Только клавиатура: всё делается текстовыми командами.
- **🧱 Строитель** — строишь подземелье мышкой: добавляешь и сносишь комнаты,
  селишь в них монстров и друзей, раскладываешь сокровища.

Режимы переключаются кнопками в правом верхнем углу.

## Как запустить

Просто открой файл `index.html` в браузере (двойной клик). Никаких серверов
и установок не нужно.

Игра сама сохраняется в браузере после каждого действия. Чтобы начать
заново — набери команду `reset`.

## ⚔️ Приключение

Слева — карта с компасом, в центре — текстовое окно, справа — твой герой.

Команды пишутся **по-английски** — как в настоящих MUD-ах. Под текстом
всегда написано, какие команды подходят прямо сейчас.

```
look              осмотреться
n, s, e, w        пойти на север, юг, восток, запад
attack            ударить врага
flee              убежать из боя
talk              поговорить
take              подобрать всё с пола
inventory  (i)    что в сумке
equip sword       взять меч в руку
equip shield      взять щит в руку
remove shield     убрать щит в сумку
use potion        выпить зелье
drop potion       бросить зелье на пол
help              все команды
```

В окне героя у каждого предмета в квадратных скобках написано, каким словом
его называть в командах: `🔰 Железный щит [iron shield]`.

## 🧱 Строитель

- Клик по **пунктирной клетке** — построить там комнату.
- Клик по **комнате** — выбрать её и настроить справа: название, описание,
  монстр, друг, предметы и золото на полу.
- **«Поставить героя сюда»** — перенести героя в эту комнату.
- **«Снести комнату»** — удалить её. Нельзя снести вход, комнату с героем
  и комнату, без которой часть подземелья окажется отрезанной.

## Правила

- В руках две вещи: **основная рука** (меч) и **вторая рука** (щит).
- Меч добавляет урон, щит уменьшает урон от монстров.
- Бой пошаговый: ты делаешь ход — потом монстр.
- За победы даётся опыт. Новый уровень = больше здоровья и сильнее удар.
- Если проиграешь, очнёшься у входа и потеряешь половину золота.

## Что внутри

Вся игра — это **один файл `index.html`**. Его можно скинуть другу,
положить на флешку или открыть из любой папки — больше ничего не нужно.

Внутри файл разбит на части с заголовками (ищи по ним через Ctrl+F):

```
ВНЕШНИЙ ВИД               цвета и размеры (в <style> наверху)
СОДЕРЖИМОЕ ИГРЫ           ⭐ предметы, монстры, друзья — начинай отсюда!
СОСТОЯНИЕ ИГРЫ            сохранение и стартовое подземелье
МИР                       комнаты и карта
ГЕРОЙ                     здоровье, опыт, сумка, снаряжение
БОЙ                       пошаговый бой
КОМАНДЫ ПРИКЛЮЧЕНИЯ       все команды
ЭКРАН                     режимы, карта и экран приключения
РЕЖИМ «СТРОИТЕЛЬ»         экран строителя
ЗАПУСК ИГРЫ               что происходит при открытии
```
