# 🏰 Подземелье Строителя

Текстовая RPG в духе старых MUD-ов из 90-х. В неё можно **играть** — бродить
по подземелью, драться с монстрами, болтать с друзьями — и тут же **строить**
подземелье: добавлять и сносить комнаты прямо на карте.

## Как запустить

Просто открой файл `index.html` в браузере (двойной клик). Никаких серверов
и установок не нужно.

Игра сама сохраняется в браузере после каждого действия. Чтобы начать
заново — набери команду `reset`.

## Как играть

Экран состоит из трёх частей:

| Слева | В центре | Справа |
|---|---|---|
| 🗺️ Карта подземелья и компас | 📜 Текстовое окно и строка для команд | 🤺 Твой герой: здоровье, мана, сумка, снаряжение |

Команды пишутся **по-английски** — как в настоящих MUD-ах. Внизу текстового
окна всегда видно, что можно сделать прямо сейчас — на подсказки можно нажимать.

Самые главные команды:

```
look              осмотреться
n, s, e, w        пойти на север, юг, восток, запад
attack            ударить врага
cast fireball     огненный шар
cast heal         лечение
flee              убежать из боя
talk              поговорить
take              подобрать всё с пола
equip sword       взять меч в руку
use potion        выпить зелье
build east        построить комнату на востоке
name Логово       дать название комнате
help              все команды
```

## Как строить

Над картой есть кнопки-«кисти». Выбери кисть и кликай по карте:

- 🚶 **Ходить** — клик по соседней комнате ведёт туда
- 🧱 **Комната** — клик по пунктирной клетке строит пустую комнату
- 👹 **Монстр**, 🙂 **Друг**, 💰 **Клад** — строят комнату с этим или добавляют в уже готовую
- ❌ **Снести** — удаляет комнату

Чем дальше от входа, тем сильнее монстры!

## Правила

- **СИЛ** (str) — сила удара мечом и запас здоровья.
- **ИНТ** (int) — сила заклинаний и запас маны.
- В руках две вещи: **основная рука** (меч или посох) и **вторая рука** (щит).
- Бой пошаговый: ты делаешь ход — потом монстр.
- Огненный шар игнорирует броню монстра, а удар мечом — нет.
- На новом уровне ты получаешь 2 очка: `train str` или `train int`.
- Если проиграешь, очнёшься у входа и потеряешь половину золота.
